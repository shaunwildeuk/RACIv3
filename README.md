# RACIv3 Decision-Grade Authority Model

This repository contains:

- RACIv3 specification
- Interactive visual model (React)
- Slide-ready assets
- Supporting documentation

## Purpose
To operationalise accountability through:
- Accountability Activation Rules (AAR)
- Abdication Detection and Prevention (ADP)
- Leadership behaviour integration

## How to Use This Model
1. Identify a decision
2. Classify its criticality
3. Determine whether Accountability (A) should be:
   - Passive
   - Conditional
   - Active
4. Test:
   - Was A required?
   - Did A engage?
5. If not → governance failure (ADP)

This model is designed to expose breakdowns in accountability at the moment of decision.
